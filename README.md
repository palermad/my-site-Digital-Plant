# Цифровой завод — сайт

Сайт ООО «Цифровой завод»: роботизация производства и цифровая платформа СМК.
Статические HTML/CSS/JS без сборки, зависимостей и внешних ресурсов.

## Структура

```
my-site-Digital-Plant/
  index.html          — Главная: направления, услуги, порядок работ
  services.html       — Услуги: вкладки «Роботизация» и «Цифровая платформа СМК»
  robotization.html   — Роботизация: операции, состав ячейки, этапы
  smk.html            — Цифровая платформа СМК (каркас под наполнение)
  contacts.html       — Контакты и частые вопросы
  404.html            — Страница ошибки для GitHub Pages
  assets/styles.css   — дизайн-система: тёмно-синие токены, сетки, адаптив
  assets/site.js      — мобильное меню, вкладки услуг, появление блоков
  README.md
```

Входной файл — `index.html`.

## Дизайн-система

Тёмно-синяя палитра, токены в `assets/styles.css`:

| Токен | Значение | Роль |
| --- | --- | --- |
| `--bg` | `#050b16` | основной фон |
| `--bg-soft` | `#081223` | фон чередующихся секций |
| `--panel` | `#0b1a30` | карточки |
| `--line` | `#1b3153` | границы |
| `--text` | `#e9f0fb` | основной текст |
| `--muted` | `#94a7c6` | вторичный текст |
| `--accent` / `--accent-hi` | `#3f7cff` / `#6ea0ff` | акценты, кнопки, ссылки |

Шрифт — системный (Segoe UI / system-ui), моноширинный — для служебных подписей.

## Локальный просмотр

Открыть `index.html` в браузере. Для проверки относительных ссылок между
страницами удобнее сервер:

```
python -m http.server 8000
```

multitool-node --skill websites site.cjs check-directory my-site-Digital-Plant
multitool-node --skill websites verify.cjs my-site-Digital-Plant/index.html --actions actions.json
multitool-node --skill websites verify.cjs my-site-Digital-Plant/services.html --actions actions-tabs.json

## Что нужно наполнить

- **`smk.html`** — раздел цифровой платформы СМК: модули, экранные формы, схема архитектуры, условия. Сейчас это каркас с черновиком.
- **`contacts.html` и подвал всех страниц** — реальные почта, телефон, адрес, часы работы (сейчас заглушки в домене `.example`).
- **Тексты услуг** — состав работ, названия модулей, ограничения по оборудованию.
- **`robotization.html`** — при необходимости добавить фото/схемы ячеек в раздел «Из чего состоит ячейка».

## Ограничения

- Форм отправки нет: у статического сайта нет сервера, поэтому на странице контактов указана почта.
- Внешних шрифтов и CDN нет — сайт работает без интернета.
