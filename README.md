# Цифровой завод — сайт

Сайт ООО «Цифровой завод»: роботизация производства и цифровая платформа СМК.
Статические HTML/CSS/JS без сборки, зависимостей и внешних ресурсов.

## Структура

```
digit-plant.ru/
  index.html                 — Главная: направления, услуги, порядок работ, совет директоров
  services.html              — Услуги: направления парами, формы сотрудничества
  robotization.html          — Роботизация: описание направления и приглашение к задаче
  smk.html                   — Цифровая платформа СМК: модули, услуги, экран платформы
  contacts.html              — Контакты и частые вопросы
  404.html                   — Страница ошибки для GitHub Pages
  CNAME                      — домен для GitHub Pages: www.digit-plant.ru
  robots.txt                 — разрешение обхода и ссылка на sitemap
  sitemap.xml                — карта сайта на основном адресе
  .nojekyll                  — отключает обработку Jekyll на GitHub Pages
  assets/styles.css          — дизайн-система: тёмно-синие токены, сетки, адаптив
  assets/site.js             — мобильное меню, переключатели направлений, карусель
  assets/favicon.svg         — иконка сайта в векторном виде
  assets/favicon-512.png     — растровая иконка
  assets/apple-touch-icon.png— иконка для iOS
  assets/og-cover.png        — обложка 1200×630 для соцсетей
  README.md
```

Входной файл — `index.html`.

## Дизайн-система

Тёмно-синяя палитра, токены в `assets/styles.css`:

| Токен | Значение | Роль |
| --- | --- | --- |
| `--bg` | `#050b16` | основной фон |
| `--bg-soft` | `#081223` | фон чередующихся секций |
| `--panel` | `#0b1a30` | карточки |
| `--line` | `#1b3153` | границы |
| `--text` | `#e9f0fb` | основной текст |
| `--muted` | `#94a7c6` | вторичный текст |
| `--accent` / `--accent-hi` | `#3f7cff` / `#6ea0ff` | акценты, кнопки, ссылки |

Шрифт — системный (Segoe UI / system-ui), моноширинный — для служебных подписей.

## Локальный просмотр

Открыть `index.html` в браузере. Для проверки относительных ссылок между
страницами удобнее сервер:

```
python -m http.server 8000
```

## Домен и публикация

Сайт публикуется на GitHub Pages из репозитория
`https://github.com/palermad/my-site-Digital-Plant`, ветка `main`, папка `/ (root)`.

Основной адрес — `https://www.digit-plant.ru`. Адрес без `www`
(`https://digit-plant.ru`) перенаправляется на основной, поэтому работает тоже.
`CNAME` в корне репозитория содержит `www.digit-plant.ru`.

### DNS-записи

У регистратора домена `digit-plant.ru`:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| AAAA | @ | 2606:50c0:8000::153 |
| AAAA | @ | 2606:50c0:8001::153 |
| AAAA | @ | 2606:50c0:8002::153 |
| AAAA | @ | 2606:50c0:8003::153 |
| CNAME | www | palermad.github.io |

### Включение домена на GitHub

1. Репозиторий → Settings → Pages.
2. В поле Custom domain вписать `www.digit-plant.ru` и сохранить. Проверка DNS может занять до часа.
3. Дождаться выпуска сертификата и включить **Enforce HTTPS**.

После включения домена сайт будет доступен по адресу
`https://www.digit-plant.ru`, а прежний `palermad.github.io/my-site-Digital-Plant/`
станет перенаправлением.

### Обновление сайта

```
git add -A
git commit -m "…"
git push
```

Pages пересобирается автоматически в течение минуты после пуша.

## Ограничения

- Форм отправки нет: у статического сайта нет сервера, поэтому на странице контактов указана почта.
- Внешних шрифтов и CDN нет — сайт работает без интернета.
